# Contributing

Thanks for helping improve `paidmcp/directory`.

## Before opening a PR

1. Read `README.md` listing requirements.
2. Keep changes focused (data validation, listing flow, UI, or docs).
3. Run checks:

```bash
npm run check
npm run format:check
```

## PR checklist

- Clear summary and rationale
- Relevant screenshots for UI changes
- `directory.json` entries validated
- No secrets or private data in commits

Solo-maintained project: responses can be delayed sometimes.
